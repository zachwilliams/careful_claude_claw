1. Daily briefing 
    1. Check my current to-do list the to-do list includes reminders as well as explicit tasks with deadlines. We will need to define a to-do list object and manage it. We can probably create a skill for this. Every morning I wanna be able to see initially only the critical to-do items and reminders. 
    2. check my emails: I want to check my emails every morning and identify any emails that require immediate response. This should be able to support multiple Google inboxes, including my personal and work inbox. 
    3. check slack: this is very similar to email: what are my unread messages? Of those what are important, as well as a general summary of what I've missed
    4. I would like a general what i missed summary based on email and slack. this can also be a skill (or part of one) that handles on vacation or marks updates i didn’t receive/review
    5. I also want to review my calendars for the day/week to see if there's anything critical coming up. We should be able to support multiple calendars, including my work and personal calendar. 
2. project log and management
    1. I want to keep track of a list of active projects. Projects are different from to-do items because they have agents associated with them, which may or may not be working. Each project can also contain its own individual set of to-do items.
    2. I want to be able to query to see the current state of a project so each project should probably maintain a plan.md as well as a current status 
    3. I want to be able to see a report on all of the agents that are actively running including what project they're working on and how long they have been active  
    4. I want to be able to see a directory of all of the skills that I have. This includes project-specific skills as well as global skills. I would also like to be able to query to get summaries of them. We can think of this as basic skill management. 
    5. Ideally there is a hosted HTML dashboard that contains this information that displays it visually 
3. learning
    1. I want to be able to provide a YouTube video link to a set of YouTube videos/playlist and get a summary of the transcripts 
4. communications management:
    1. Outside of the daily briefing I want the ability to just generally catch up on things: emails, slags, etc. Get summaries, see where stuff is at, and then be able to automate replies these automations should be sent to me first for confirmation. 
5. coding
    1. I want a set of skills defined so that across all projects when we are writing code, we are doing it in a consistent way specifically I want to make sure that we are using Git and that I am able to personally review on GitHub all of the code prior to it being merged in. We should make sure that all the projects have protections. 
    2. I want to have a coding environment that enables me to use Neovim to review the current state of code, what the agents are actively working on, and make manual adjustments to code as if I was their boss 
6. relationship manager
    1. I want to build a list of everybody i know and track our relationship status. Specifically this means:
        1. having a general summary of the last time we chatted
        2. a high-level sentiment analysis based on all the conversations we have
        3. the most important thing is when we last connected or communicated and what that was regarding (flag)
    2. I'd love to connect this to their LinkedIn if possible, as well as any social media accounts that I have, so that I can ask questions like "What is this person up to?" “Who on my list can help me solve this problem?”
